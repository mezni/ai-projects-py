# Prompt Optimizer Skill

When asked to optimize, refine, or rewrite a prompt, follow this framework:

1. **Role & Goal:** Define who the AI is and what outcome is expected.
2. **Context & Constraints:** Set background, constraints, tone, and length limits.
3. **Inputs & Formatting:** Define exact input formats and output schemas (e.g., JSON, Markdown).

## Output Format
Always present the output in two sections:
- **Optimized Prompt:** The final, ready-to-use prompt inside a code block.
- **Key Enhancements:** 2–3 bullet points explaining why the changes improve prompt adherence.
